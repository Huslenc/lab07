ДүгнэлтХайгуулын тест (Exploratory Testing) нь урьдчилан бичсэн хатуу тест кейсээс ялгаатай нь тестер системийн зан төлөвийг ажиглах явцдаа дараагийн туршилтаа уян хатан төлөвлөх боломж олгодог. Ялангуяа UI түвшинд зөв мэт харагдах үйлдлийг curl -i ашиглан API түвшинд шууд шалгахад сервер талын баталгаажуулалтын дутагдал тодорхой илэрсэн. Түүнчлэн charter.md-г эхэлж баталгаажуулах, 60 минутын турш тасралтгүй HH:MM тэмдэглэл хөтлөх, согог бүрийг түүхий HTTP нотолгоотой (evidence/) холбох нь тестийн үр дүнг дахин давтах, баталгаажуулахад чухал ач холбогдолтой байлаа.
