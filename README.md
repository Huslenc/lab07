## Тойм
Энэхүү лабораторийн ажил нь «Уншлагын жагсаалт» вэб апп дээр session-based
test management (SBTM) аргыг бүрэн хэрэгжүүлсэн: charter бичих, 60 минутын
тасалдалгүй exploratory session хийх, session report хөтлөх, олдсон согог
бүрд мэргэжлийн түвшний алдааны тайлан бичих.

- Аппыг ажиллуулах: node app.js → http://localhost:3000
- Бүтэц:
  - charter.md — session-ээс өмнө commit хийсэн төлөвлөгөө
  - session-report.md — 60 минутын session-ийн тэмдэглэл, цагийн задаргаа
  - bugs/bug-0N.md — согог бүрийн алдааны тайлан
  - evidence/ — API согогийн curl -i гаралт
  - screenshots/ — UI согогийн скриншот
